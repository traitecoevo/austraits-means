# Portal inputs

`trait_groups_for_portal.csv` is the AusTraits data portal's trait grouping table, including the `core_trait` column that selects the 96 traits the portal computes species means for. It was deleted from the portal in commit `dc8a965`; this copy is the file as it stood immediately before that commit, recovered with

```sh
git -C austraits.portal show dc8a965^:inst/extdata/austraits/trait_groups_for_portal.csv
```

It is identical to the file at portal commit `13479b9`, the commit that built the deployed AusTraits 7.0.0 data. `read_portal_core_traits()` keeps the rows where `core_trait` is not `NA`, as `prepare_data_for_portal()` did. Four of the 96 core traits have no records in AusTraits 7.0.0 (`leaf_hairs_juvenile_leaves`, `leaf_axil_angle`, `stem_density`, `climbing_plant_height`), so the product covers 92.

Do not edit this file: it is a pinned input to the species means 7.0.0 product.
